Correção da transparência

No Reparar alfa, pixels com alfa neste valor ou acima ficam sólidos, mesmo se o limite de opacidade estiver maior. Também guia a busca de cores de borda.

Preenche furos internos com largura E altura dentro do limite. Reconstitui a cor a partir da borda; examine letras e detalhes.

0 = desligado. Remove componentes isolados cuja largura E altura caibam no limite selecionado, inclusive se forem opacos. Atenção a pontos decorativos.

128 = 50%. 0 preserva todo pixel com alfa acima de zero. Maior recorta mais a borda.

Leve, Média e Alta aplicam critérios diferentes sobre pixels parcialmente transparentes. Pixels originalmente opacos são preservados.

Mescla a cor de pixels de alta opacidade próximos para reduzir contaminações nas bordas. Ajuste de 0 a 100%.

Reparar alfa: modo experimental para imagens com muita semitransparência, com fechamento de furos e correção de bordas.
